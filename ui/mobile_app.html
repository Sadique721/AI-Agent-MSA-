🔐 Privacy Policy & Terms
100% Local · No Cloud · No Tracking

📖 Overview

MSA AI Agent is a private, offline-first AI assistant developed by Md Sadique Amin. This application runs entirely on your local network and does not transmit your data to any external server, cloud provider, or third-party service.

🔒 Data Collection

MSA Agent collects and stores the following data locally on your device only:

  • Voice commands and text inputs (encrypted in local SQLite database)
  • Agent responses and action history
  • GPS coordinates when you choose to share them via the Location feature
  • System resource metrics (CPU, RAM, Disk) for display purposes only

🛡 Data Security

  • All conversation history is encrypted using Fernet symmetric encryption
  • Encryption keys are stored locally in your device's file system
  • API key authentication protects all HTTP endpoints
  • The server only listens on your local network (0.0.0.0:5000)
  • No data is ever sent to external servers

🌐 Internet Usage

MSA Agent may make outbound internet requests only when:

  • You explicitly request a web search (DuckDuckGo)
  • The UI loads fonts from Google Fonts (one-time)
  • The UI loads Socket.IO library from CDN (one-time)

These requests do not include any personal data.

🎙 Voice & Microphone

The voice feature uses your device's microphone only when you activate it by pressing the mic button. Voice data is processed locally using the Vosk speech recognition model. No audio is transmitted externally.

📍 Location

Location access is only requested when you explicitly tap "Share GPS Location." Coordinates are sent only to your local MSA Agent server and are not stored persistently or shared.

📱 Mobile Control

The ADB (Android Debug Bridge) mobile control feature connects to your Android device on your local network only. No commands are relayed to external services.

📜 Terms of Use

  • MSA Agent is for personal use only by Md Sadique Amin
  • Do not expose the server port (5000) to the public internet
  • The default API key should be changed in production use
  • MSA Agent is provided as-is with no warranty
  • System control commands (shutdown, restart) execute immediately
