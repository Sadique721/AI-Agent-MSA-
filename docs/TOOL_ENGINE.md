# Tool Engine — MSA AI Agent V4.5

Details registered desktop automation tools, permissions, and validation procedures.

## Registry Functions

- **Browser**: Playwright-based workspace scrapers.
- **Terminal**: Native OS command runner.
- **System**: Notepad, calc, and native clipboard copy-paste actions.
- **File System**: Local file readers, writers, and pickers.

All raw output is serialized to JSON and routed through the LLM manager for synthesis.
